# Tweeter

A twitter clone. Complete with user authentication using OAuth and real time communication with database using socket.io.

# [Click here for live Demo.](https://tweeterdemo.xyz)

## Built With

These are the main technologies used to build the foundadtions of the app.

- [React](https://reactjs.org/) & [React Redux](https://react-redux.js.org/) - The front-end framework used
- [Express](https://expressjs.com/) & [Node.js](https://nodejs.org/en/) - Used for backend API server
- [OAuth](https://oauth.net/) - Used for authentication
- [Socket.IO](https://socket.io/) - For real-time data transfers
- [MySQL](https://www.mysql.com/) with [Docker](https://www.docker.com/) - Used as database
- [Nginx](https://www.nginx.com/) - As proxy server for deployment
- [Amazon Web Services](https://aws.amazon.com/) - Used as the web server for the [live demo](https://tweeterdemo.xyz)
